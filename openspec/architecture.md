Note 1: the engine edge is HOST-INITIATED — the engine spawns the runner (or dynamic-imports the bridge in its own process) and sends the first frame (`{method:"ready", protocolVersion}`); the SDK then owns the raw read loop (ADR-0054, single reader) and issues reverse callbacks. The wire is NOT JSON-RPC 2.0 — it is the repo's own framed JSON `{type:"request"|"response", id:"s<n>", method, params}` grammar, normatively pinned in docs/engine-sdk-wire-spec.md (fit-33/fit-34 pin the constants against that doc at test time).
Note 2: ts-morph stays LEAF-ISOLATED (FIT-01 typescript-leaf walk + FIT-37 repo-wide transitive core/commons AST-freedom walk; FIT-38 pins parser construction to the two authorized `ast.ts` leaves non-vacuously). The `./typescript` and `./react` edges are in-process; only printed `[]byte` crosses the IR seam.
Note 3: `./conformance`'s run-vehicle satisfies the port SHAPE via a LOCAL structural interface — never names `EngineClient` (FIT-10) and is never re-exported (FIT-08).
Note 4: `./testing` and `pbuilder-codegen` retain their in-memory/write-contained postures; `./testing`'s `defineFactory` edge plus `src/core/**`/`src/conformance/**`/`src/transport/runner.ts` are the ONLY sanctioned production paths to `defineFactory` (FIT-29).
Note 5 (**NEW — trust-boundary relocation, ADR-0077**): the SDK no longer holds a containment ceiling for package-local reads. By-reference paths are bounded by the ENGINE's apply-time re-derivation (`by-reference-copy-wire` REQ-BRC-02 — LIVE, and the SDK-resolved root was never wire-authoritative anyway); by-value/inline bytes have NO boundary control on either side, accepted under the v1 trusted-author model and documented in `SECURITY.md` §"Package-local read trust posture (v1)". The engine edge is therefore now a SECURITY boundary in one more respect than before.

## Pattern
- @pbuilder/sdk: custom — layered modules behind an IR-seam port, dialect leaves, and a transport leaf realizing the port
  Evidence: `src/commons/` (author verbs) → `src/core/` (Session, DirectiveFactory, handle-state, dialect-handle) → `src/core/wire.ts` (Directive/Batch shapes + cap seam) → `src/core/engine-client.ts` (single `EngineClient` port) ← `src/transport/stdio-engine-client.ts` (first real implementer). `src/dialects/{typescript,react}/`, `src/dry-run/`, `src/testing/`, `src/scaffold/`, `src/transport/` sit beside `core` as deliberately-isolated leaves. No `adapters/`/`ports/`/`usecases/`/`domain/` scaffold; the seam is one interface.
- **`src/transport/` cluster (ADRs 0053-0059)**: strict internal ownership — `framing.ts` single owner of encode/decode + the only sanctioned stdout reference (fit-30/fit-31); `core/wire.ts` owns the single `> BATCH_CAP_BYTES` comparison both legs share (fit-32); `runner.ts` is the ONE composition root both entry vehicles share; `stdio-engine-client.ts` is the only transport file allowed to name `EngineClient` (fit-10 +1). ## Data flow
- Author verb → `DirectiveFactory.{op}` → `Session.buffer` → (read() or run-end) → `Session.flush()` → `EngineClient.emit(Batch)` → engine.
- Read path: `read()` → `Session.read(path)` → flush (read-your-own-writes) → `EngineClient.read(path): Promise<string | undefined>`.
- Run lifecycle: `defineFactory<O>(fn, options?)` → **`checkReservedNames(packageDir)` → `validateAtRunBoundary(packageDir, input)` → seed `packageAnchors = { packageDir }`** → ALS RunContext → fn → `dialects.drain()` → `flush()` → `commit()`/`discard()`; all-or-nothing. **A package with no `collection.json` anywhere on its ancestor chain now runs normally — the reported inline-collection bug, closed.**
- **Runner flow**: engine spawns `src/bin/pbuilder-runner.ts` (or bootstrap dynamic-imports `enterBridge`) → fd-1 frame writer captured + console redirected FIRST → `runRunner(argv, io)`: parse argv (RUN-01) → resolve input inline/file (RUN-04, 10 MiB cap, fail-closed JSON parse with line/column locator, no raw-content echo) → await versioned `ready` greeting (WPS-02) → single-instance probe (SEC-07, before import) → `import(factoryUrl)` (RUN-07) → export resolution + double-wrap check (RUN-03/06) → `defineFactory(fn, {packageDir: dirname(factory)})` (RUN-05) → `run(input, {client: new StdioEngineClient(channel)})` → exit 0, or classify (EXC-01; EXC-02 never reads `.cause`).
- **Wire flow (per reverse callback)**: `StdioEngineClient.#call` enqueues on the internal `#chain` (single-in-flight) → mints `s<n>` id → writes ONE request frame → `#awaitResponse` races the matching read loop against the injectable timeout — timeout abandons the call without consuming the successor's frame; non-matching frames are wire-silently discarded with a bounded stderr note (WPS-03). `emit` pre-checks `exceedsEmitBatchBudget(batch)` LOCALLY and hands the exactly-once-serialized body to the writer via `withPreserializedBody`. Host error envelopes: ir.emit → reconstructed `EmitRejection`; tree.read/ir.commit/ir.discard → `IntentRejectedError`.
- **Cap seam (two legs, one comparison)**: OUTBOUND — `EMIT_BATCH_BUDGET_BYTES = BATCH_CAP_BYTES − EMIT_FRAME_ENVELOPE_ALLOWANCE_BYTES` via `exceedsEmitBatchBudget`, shared by StdioEngineClient + ContractFake (FEH-01) + scaffold; INBOUND — raw declared length checked reject-before-alloc in FrameReader via `exceedsBatchCap(number)`. The single `> BATCH_CAP_BYTES` comparison lives in wire.ts (fit-32); `>` never `>=`.
- **Dialect flow (ADR-0037 + amendment)**: `find(path)` → `createDialectHandle(ast, ops, path)` returns a thenable `Handle`; each op/`.modify(fn)`/write verb enqueues a step on `#tail` and self-registers on `ctx.dialects`; N edits coalesce to ONE `modify` (mutation gate: a true no-op emits ZERO directives); a global mid-chain read/flush produces the exactly-two-modifies split; run-scoped poison flag fails a run closed first-wins; `dialects.drain()` awaits every handle before flush.
- **Scaffold / by-reference flow (REWRITTEN, `inline-collection-marker`)**: `scaffold(args)` → `currentContext()` → `requirePackageAnchors()` (no `packageDir` ⇒ `invalid-input`, "there is no resolution anchor") → `validateDestinationLexical(args.to)` → `validateNonDegenerateFrom(args.from)` (ruling 17: `""`/`"."`/`"./"` reject) → `validateFilterOptionShape(include/exclude)` → **`validateSourceLexical(args.from)` — screen BEFORE the walk, so an escaping `from` never enumerates a tree** → `walkFolder(join(packageDir, args.from))` (bounded 10 000 entries; `lstatSync` before `readdirSync` so a SYMLINKED ROOT rejects rather than being silently followed, ruling 16; nested symlinked directories still skipped) → filename-pipeline (pure rename → token → `.template`-strip + glob) → per-entry destination re-validation post-rename → classify-transport (`statSourceForRead` size gate → UTF-8/null-byte sniff → serialized-budget verdict → by-value `create` or by-reference `copyIn`) → expander (serialized-size chunked flush before `EMIT_BATCH_BUDGET_BYTES`). `copyIn` runs the same order (`ctx → packageDir → destination → source-lexical → statSourceForRead`) and is always by-reference, `void`-returning. **There is no containment step anywhere in this chain any more, and no `realpath` call: the emitted by-reference path is a package-relative RESOLUTION anchor the engine re-derives its own ceiling from (REQ-BRC-02/REQ-BRC-07); no SDK-resolved root value is ever wire-authoritative.**
- **Conformance / run-boundary validation / codegen / error attribution / dry-run** — otherwise unchanged.
